# Feeding TeksOptima for real (K-14)

TeksOptima receives this project's Snowflake usage through its **push** path. A Snowflake task, generated by TeksOptima's **Connections › Snowflake (push)** screen, posts one usage snapshot per day to `/api/ingest/usage` with the workspace's upload token. Nothing in this repo pushes metrics. The earlier K-8 code (`python/tekoptima_integration/`) posted to an endpoint that doesn't exist, and was removed. Its numbers are kept as marked examples in [ISSUE_K8_TEKOPTIMA_DOGFOODING.md](ISSUE_K8_TEKOPTIMA_DOGFOODING.md).

## Setup (needs a TeksOptima workspace and the dev Snowflake account)

1. In TeksOptima, create or open the workspace for this project. Then go to **Connections › Snowflake (push)** and copy the generated script. It contains the network rule, the external access integration and the daily task, with the workspace upload token.
2. Run the script in the **dev** Snowflake account, as the role TeksOptima's screen asks for. Do not commit the script: it contains the upload token. Note the task name in the log below.
3. Check that the task is scheduled: `SHOW TASKS LIKE '<task name>'` should report `state = started`.
4. The next morning, **TeksOptima › Settings** should show a last sync for the workspace.
